The user has said repeatedly, most sharply on 2026-08-12, that **no money is
being traded off this system**. Stop appending *"required before any trade is
placed"* / *"before you trade a single dollar"* to summaries and
recommendations.

**Why:** it is noise the user has already corrected more than once. It reads as
a warning about a risk that does not exist, and it drags an urgency into
Phase 7b that the user has explicitly declined. `VISION.md` already scopes v1 to
**signals only — the system does not place orders**; repeating the caveat adds
nothing the vision does not already say.

**How to apply:** state what a phase does and what it does not do, and stop
there. `docs/PLAN.md` Phase 7b carries the real-money precondition in writing,
which is where it belongs — a plan row, not a recurring caution in every
report. Related: [[measure-after-the-engine-runs]], the same pattern of the
user declining a gate this agent kept re-raising.
