## §3 Step 3 High / Step 3 Low

**Citation-integrity finding, load-bearing for every row below that cites `DIA-P`.** `md5` checksums show `DIA-P`
(`edu/123sequence/1-2-3-PTB-Long.svg`), `DIA-L` (`edu/123sequence/entry_technique/step-3-pullback-diagram.svg`), and
`edu/123sequence/entry_technique/step-1-2-3.svg` are all **byte-identical** (same MD5:
`5db99292665d2f688ee34531688444ad`; `diff` between `DIA-P` and `DIA-L` returns no differences). The rulebook's own
citation-key table (§0) discloses that `DIA-L` is "byte-identical to `step-1-2-3.svg`," but does not disclose that
`DIA-P` — described there as "(bullish, PTB-annotated)," as if distinct — is the same file too. Any rule below that
treats `DIA-P` as a citation independent of `DIA-L` is citing the same bytes twice. This does not make the geometric
claims in 3.2/3.6/5.2.4/5.3.6 false (verified correct against the actual SVG coordinates, below) — it only means
`DIA-P` supplies no evidence beyond what `DIA-L` already supplies.
