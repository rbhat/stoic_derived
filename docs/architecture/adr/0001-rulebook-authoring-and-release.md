# ADR-0001: Separate Rulebook Authoring from Published Releases

- Status: Accepted
- Date: 2026-07-24

## Context

The strategy must be understandable to a human and deterministic for SP2.
Free-form prose is hard to validate, while making generated JSON the authoring
format makes review unnecessarily difficult.

## Decision

We will author the rulebook in strict YAML, generate a Markdown review
projection, and publish canonical immutable JSON for SP2. YAML is the only
authoring authority; Markdown and JSON are derived.

## Consequences

- Review remains human-friendly and SP2 receives a stable offline artifact.
- A small compiler and drift checks are required.
- SP2 cannot load draft YAML or raw research material.

## Compliance

Fitness tests compare generated bytes, reject manual projection drift, and
restrict SP2 loading to a published JSON manifest with a verified digest.
